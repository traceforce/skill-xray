# SARIF schema

`sarif-schema-2.1.0.json` is the unmodified OASIS SARIF 2.1.0 Errata 01
operating schema, vendored unchanged and embedded into the binary with go:embed.
A test pins its SHA-256; restore altered bytes from a trusted checkout.
All schema references are local; runtime validation never downloads a schema.

Source: https://docs.oasis-open.org/sarif/sarif/v2.1.0/errata01/os/schemas/sarif-schema-2.1.0.json
